# homebrew-tap

```sh
brew install --cask gee-m/tap/screen-local-dock
```

Screen-local Dock: the windows on this screen, within reach. A per-display dock for macOS, summoned by a wiggle. Details and a direct DMG at https://guillaume.ai/apps.

Developer preview, ad-hoc signed: on first launch use Open Anyway in System Settings > Privacy & Security, then grant Accessibility. The app updates itself afterwards.
